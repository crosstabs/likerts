What stays under your control.

Are responses really unlimited?

Likerts does not meter or charge responses. Operators should still configure request rates, payload bounds and infrastructure capacity to protect their deployment.

Does Likerts host or distribute survey links?

No. Your web or mobile product decides when, where and to whom a survey appears.

Can an AI agent manage Likerts?

Yes. The MCP server exposes the same scoped operations as the API and CLI, so Codex or Claude can create surveys, manage collections, retrieve responses and run exports.

Can I use it for multiple customers?

Yes. Each workspace is isolated with row-level security and scoped credentials. Deploy separate stacks when a customer requires physical isolation.
