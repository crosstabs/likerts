A few things
worth knowing.
Is Likerts a hosted form builder?
Likerts is survey infrastructure for developers. Define surveys through the API, MCP or CLI, then embed them in your product with an SDK. There is no drag-and-drop form builder or public survey link service.
What's free, and what do I pay for?
The software is free under the MIT license, including commercial use. Likerts doesn't charge per response or require a paid plan. You pay for the servers, database and storage you use to run it.
Can I use my own UI?
Yes. Use the collection API directly or an SDK client with your own interface. The Web SDK also includes a renderer you can try in the live demo.
Can one deployment serve multiple customers?
Yes. Workspaces separate data through PostgreSQL row-level security and scoped credentials. You can also run separate deployments for customers who require dedicated infrastructure.
