# Code of Conduct

Likerts welcomes people with different backgrounds, experience levels and viewpoints. This applies to repository issues, pull requests, discussions and other spaces maintained for the project.

Be considerate and specific. Critique the work, explain your reasoning, ask questions before assuming intent and leave room for people to learn. Respect a contributor's time and a maintainer's decision to defer a change. Disagreement is welcome; personal attacks are not.

Harassment, discriminatory language, threats, sexual harassment, doxxing, impersonation and repeated disruption are unacceptable. Do not publish someone's private information or contact them repeatedly after they ask you to stop.

## Reporting and enforcement

Report an abusive GitHub comment through GitHub's **Report content** action. For a matter that needs project moderation, use the repository owner's contact information when a private channel is listed on their [GitHub profile](https://github.com/crosstabs). Do not create a public issue containing private evidence. This project currently has no dedicated confidential conduct-report mailbox.

Maintainers may edit or remove content, ask a participant to change behavior, lock a thread or restrict participation. The response should reflect the severity, context and repetition of the behavior. Where practical, maintainers explain the reason and a way to address the decision. A maintainer involved in a dispute should seek another maintainer's review when one is available.

Security vulnerabilities have a separate [reporting process](SECURITY.md). Participation does not require sharing personal information.
