# Changelog

## 0.0.1 — 2026-09-08

- Kotlin collection client and Compose six-type renderer with presets, labels and selection bounds.
- Cancellable coroutine transport, immutable configuration cache and host-controlled submission/presentation.
- Local Maven artifact with AAR, source JAR and transitive dependency metadata, plus a clean consumer build.

Local evaluation repository for API 26+, Kotlin 2.1.20 and the recorded Compose matrix. No Maven registry publication; physical-device release checks remain separate.
