# Changelog

## 0.0.3 — 2026-09-09

- Schema 5 adds ranking, single/multiple matrix and exact-total constant-sum questions with bounded answer schemas.
- Compose controls use explicit rank movement, stacked matrix rows and an announced constant-sum remainder.

## 0.0.2 — 2026-09-09

- Schema 3 adds conditional visibility, structured Other text, exclusive None choices, stars and dropdown presentations. Existing schema 1/2 answers remain compatible.
- Schema 4 adds pages, forward routing, page validation, Back/Next navigation, progress and removal of skipped answers.
- Host-controlled triggers, submission and distribution remain unchanged. No package publication.

## 0.0.1 — 2026-09-08

- Kotlin collection client and Compose six-type renderer with presets, labels and selection bounds.
- Cancellable coroutine transport, immutable configuration cache and host-controlled submission/presentation.
- Local Maven artifact with AAR, source JAR and transitive dependency metadata, plus a clean consumer build.

Local evaluation repository for API 26+, Kotlin 2.1.20 and the recorded Compose matrix. No Maven registry publication; physical-device release checks remain separate.
