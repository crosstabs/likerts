# Contributing

Issues and pull requests are welcome. Keep changes focused, include the user-visible reason for the change and run the checks that match the affected area.

For the full local gate:

```bash
bash scripts/check.sh
bash scripts/check-postgres.sh
bash scripts/check-all-sdks.sh
```

Do not commit credentials, customer data, generated build directories or private validation evidence. By contributing, you agree that your contribution is licensed under the repository's MIT License.
